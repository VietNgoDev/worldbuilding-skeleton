# About Maps

Put map images in this folder.

## How to use

1. Drop image files here — exports from any map tool or scans. Keep filenames lowercase and descriptive: `region-overview.png`, `capital-wards.png`.
2. Embed a map in a note with `![[region-overview.png]]`.
3. Give each major map a companion note in this folder that embeds the image and links each labeled place to its note, so the map participates in the graph instead of being a dead end.

## Suggested set

- One overview of the main region.
- One local map per settlement or adventuring area.
- Optional: the same area at different states (seasons, war, flood).
